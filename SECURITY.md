# Security policy

## Supported release

This policy covers the current release, v1.0.0, on GNOME Shell 51. Other Shell versions and unpublished local variants are outside the supported scope.

## Report a vulnerability privately

Open the repository's [Security Advisories page](https://github.com/thinkhome-org/gnome-start-minimized/security/advisories) and select **Report a vulnerability**. If the button is unavailable, open an issue asking maintainers to provide a private contact method. Do not include vulnerability details, affected components, logs, or attachments in that issue.

In the private report, include the affected extension version, GNOME Shell version, prerequisites, a concise description of the impact, and the smallest safe set of steps needed to verify it. Redact secrets, personal data, and identifying paths. Let maintainers know if there is a workaround or a planned disclosure date so they can coordinate with you.

Use the public bug template for problems without a security impact, such as a window failing to minimize.
